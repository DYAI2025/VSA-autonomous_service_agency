## How to Monitor Output

### Quick Check
```bash
# List all recent outputs
find ~/wuphf-agency-output/ -type f -mtime -1 | sort

# Count outputs by category
ls -1 ~/wuphf-agency-output/*/*
```

### Live Monitoring
```bash
# Watch for new files
watch -n 10 'find ~/wuphf-agency-output/ -type f -mmin -10'

# Monitor specific folder
watch -n 5 'ls -lh ~/wuphf-agency-output/pitch-decks/'
```

### Search for Specific Client
```bash
# Find all files for a client
find ~/wuphf-agency-output/ -iname "*clientname*"

# Search in content
grep -r "ClientName" ~/wuphf-agency-output/
```

## Troubleshooting

**No files appearing?**
- Check agent activity: `tail -f ~/.wuphf/watchdog.log`
- Check wiki tasks: `ls ~/.wuphf/wiki/tasks/`
- Verify agents are running: `ps aux | grep wuphf`

**Files in wrong location?**
- Agents follow guidelines in: `~/.wuphf/wiki/output-guidelines.md`
- Move files manually if needed
- Update wiki task with correct location

**Need specific format?**
- Add requirements to: `~/.wuphf/wiki/output-guidelines.md`
- Agents will follow updated guidelines on next task
