# Client Onboarding Checklist

**Agency**: Autonomous Pitch Deck Agency
**Purpose**: Ensure smooth onboarding for new pitch deck clients
**Last updated**: 2026-05-18

---

## Step 1: Initial Consultation & Discovery (Day 1)

### Objective
Understand the client's business, funding goals, and timeline.

### Actions
- [ ] Schedule 60-minute kickoff call
- [ ] Send pre-meeting questionnaire:
  - Current funding stage
  - Target raise amount
  - Timeline for fundraising
  - Key team members to involve
- [ ] Review existing materials (if any):
  - Previous pitch decks
  - Financial projections
  - Market research
- [ ] Document key insights and requirements

### Deliverables
- Discovery notes document
- Initial project scope definition

---

## Step 2: Information & Asset Gathering (Day 2-3)

### Objective
Collect all necessary information and materials for pitch deck creation.

### Actions
- [ ] Request specific materials from client:
  - Company logo and brand guidelines
  - Product screenshots or demo videos
  - Team photos and bios
  - Financial data (revenue, growth metrics)
  - Market research or customer insights
  - Competitive landscape information
- [ ] Conduct stakeholder interviews:
  - Founder/CEO vision and story
  - Product/technical deep-dive
  - Sales/customer success insights
- [ ] Gather market validation:
  - Customer testimonials
  - Partnership agreements
  - Press coverage or awards

### Deliverables
- Complete asset folder with all materials
- Stakeholder interview summaries
- Information gaps document (if any)

---

## Step 3: Strategic Narrative Development (Day 4-5)

### Objective
Create the core story and strategic positioning for the pitch deck.

### Actions
- [ ] Define investment thesis:
  - Why this company now?
  - What problem do we solve?
  - Why are we uniquely positioned?
- [ ] Develop narrative arc:
  - Problem → Solution → Opportunity → Team → Ask
  - Ensure emotional and logical flow
- [ ] Create messaging framework:
  - Key value propositions
  - Differentiation points
  - Supporting evidence and proof points
- [ ] Draft deck outline (10-12 slides)
- [ ] Review with client and get feedback

### Deliverables
- Strategic narrative document
- Deck outline with slide descriptions
- Messaging framework

---

## Step 4: Pitch Deck Creation & Iteration (Day 6-10)

### Objective
Design and build the actual pitch deck based on approved narrative.

### Actions
- [ ] Create slide-by-slide content:
  - Apply Sequoia/YC framework
  - Ensure concise, impactful messaging
  - Use data visualization for key metrics
- [ ] Design visual elements:
  - Professional layout and branding
  - Consistent color scheme and typography
  - High-quality charts and graphics
- [ ] Internal review:
  - Check against strategic narrative
  - Verify data accuracy
  - Ensure flow and clarity
- [ ] Client review round 1:
  - Present complete draft
  - Gather specific feedback
  - Document revision requests
- [ ] Revisions based on feedback:
  - Address all client concerns
  - Refine messaging and design
  - Finalize content
- [ ] Final client approval:
  - Present revised version
  - Obtain sign-off
  - Document any final tweaks

### Deliverables
- Complete pitch deck (PDF + editable format)
- Design source files
- Version control documentation

---

## Step 5: Final Delivery & Handoff (Day 11)

### Objective
Ensure client has everything needed for successful fundraising.

### Actions
- [ ] Final file delivery:
  - PDF version (for sharing)
  - PowerPoint/Keynote source files
  - Font files and custom assets
  - Brand guidelines for deck
- [ ] Presentation preparation:
  - Speaker notes for each slide
  - Key talking points and data points
  - Q&A preparation document
  - Investor objection handling guide
- [ ] Follow-up support:
  - Schedule check-in call after first investor meetings
  - Offer revision package (if needed)
  - Request feedback and testimonial
- [ ] Project closure:
  - Final invoice
  - Project summary document
  - Lessons learned (internal)

### Deliverables
- Complete deliverable package
- Presentation preparation materials
- Project completion summary

## Common Pitfalls to Avoid

### Information Gaps
- **Issue**: Missing key data or assets mid-project
- **Prevention**: Comprehensive asset gathering in Step 2
- **Solution**: Build in buffer time for missing information

### Scope Creep
- **Issue**: Client keeps requesting additional slides or changes
- **Prevention**: Clear scope definition in Step 1
- **Solution**: Change order process for out-of-scope requests

### Narrative Confusion
- **Issue**: Story doesn't flow or key messages get lost
- **Prevention**: Strategic narrative development in Step 3
- **Solution: Regular check-ins on narrative alignment

### Design Inconsistency
- **Issue**: Visual style varies across slides
- **Prevention**: Brand guidelines and design system from start
- **Solution**: Design review before client presentation
